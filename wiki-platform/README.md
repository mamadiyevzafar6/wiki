# Wiki Competitions Platform

Глобальный каталог грантов, стипендий, хакатонов и интеллектуальных соревнований.

## 📋 Описание

Информационная платформа (по типу Википедии) для публикации и поиска возможностей в области образования, науки и технологий.

### Особенности

- **Публичная часть**: Поиск программ, просмотр по категориям и странам
- **Админ-панель (CMS)**: Полное управление контентом
- **Минималистичный дизайн**: Ультра-минимализм, строгая типографика
- **Безопасность**: Хэширование паролей, защита сессий, параметризованные SQL-запросы

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd wiki-platform
npm install
```

### 2. Запуск сервера

```bash
node server.js
```

Сервер запустится на `http://localhost:3000`

### 3. Первый вход в админку

1. Перейдите на `http://localhost:3000/admin/login`
2. Войдите под дефолтным админом:
   - **Логин**: `admin`
   - **Пароль**: `admin123`
3. Система потребует сменить пароль при первом входе

## 🗄️ База данных

База данных SQLite создается автоматически при первом запуске. Включает таблицы:

- **users** — администраторы
- **categories** — типы соревнований
- **countries** — страны
- **programs** — программы/гранты/соревнования
- **settings** — настройки сайта

### Начальные данные

При первом запуске создаются:
- Дефолтный админ: `admin / admin123`
- 4 категории: Хакатоны, Гранты, Стипендии, Конкурсы
- 5 стран: США, Великобритания, Германия, Россия, Международные

## 🔒 Безопасность

Реализованные меры защиты:

1. **Пароли**: Хэширование bcrypt с солью
2. **Сессии**: express-session с httpOnly cookies
3. **SQL-инъекции**: Параметризованные запросы (better-sqlite3)
4. **XSS**: Экранирование вывода в шаблонах EJS
5. **Защита роутов**: Middleware проверки авторизации для `/admin/*`
6. **Валидация**: Проверка ввода на сервере

## 📝 Функционал CMS

### Управление программами
- Создание/редактирование/удаление программ
- Поддержка Markdown в описании
- Автоматическая генерация slug из названия
- Привязка к категории и стране
- Установка дедлайна
- Статус публикации (черновик/опубликовано)

### Управление категориями и странами
- CRUD операции
- Slug для URL

### Настройки сайта
- Изменение названия сайта
- Редактирование навигационного меню (JSON)

### Управление пользователями
- Добавление новых администраторов
- Удаление пользователей (кроме последнего)
- Смена пароля

## 🔍 Поиск

- Живой поиск (live search) через Fetch API
- Поиск по программам, категориям и странам
- Автоэкранирование ввода

## 🛠️ Технологии

- **Backend**: Node.js + Express.js
- **База данных**: SQLite (better-sqlite3)
- **Шаблоны**: EJS
- **Frontend**: Vanilla JS, CSS3 (без фреймворков)
- **Аутентификация**: express-session + bcryptjs
- **Markdown**: marked
